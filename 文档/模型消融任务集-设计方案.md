## 〇、先看语料实况，它决定了任务只能长成什么样

实际索引里有什么（`cases.jsonl` 31 / `workflows.jsonl` 54 / `templates.jsonl` 1）：

| 类型 | 内容形态 | 例子（真实） |
|---|---|---|
| **case** | 失败 → 修复对 | `sqlite3` 未安装 → `python3 -c "import sqlite3"`；<br>ssh 密码认证被拒 → `ssh -i ~/.ssh/id_ed25519_seed -o BatchMode=yes` |
| **workflow** | **纯动作序列**（无意图标注） | `查代理环境变量 → 探本地代理端口 → 列凭据文件 → 直连测试` |
| template | 1 条 | — |

### 由此得出三条设计约束

**① 记忆里有两类价值，对应两类任务**

```
事实类（case）  —— 这台机器上 X 不可用/路径是什么/密钥叫什么  → 测【成败】
套路类（workflow）—— 遇到这类问题先做 A 再做 B                 → 测【效率】
```

**② 别用"通识就能答对"的题**

`netstat` → `ss` 这种，任何模型都知道，**无记忆组照样答对，测不出差异**。
出题必须挑**环境特异**的：具体路径、具体密钥文件名、这台机器特有的服务名。

**③ 🔴 现在的索引主要是 Windows 开发期内容**（VS Code 设置、v2rayN、plink、代理端口），
**不是麒麟 OS Agent 的场景**。

真正好用的麒麟侧知识（`share-kytensor-*` 服务名、`/usr` overlay 行为、
恢复脚本在 USB 挂载点、`unshare -m` 才能写 `/usr`）**在 D1~D7 的数据里，还没进索引**。

**→ 所以 20 条具体题目必须等 09-03 索引重建后再定稿。** 现在定的是方法和评分。

## 一、反向出题法（保证答案一定在记忆里）

照搬评测集那套思路，但出的是**任务**不是问题：

```
对每个知识单元问一句：
    「如果 agent 不知道这条，它会在什么任务上栽跟头？」
那个任务就是测试题，而这条单元里的 fixed_input / tool_sequence 就是标准答案。
```

**这样天然保证**：答案在记忆里、无记忆组没有别处可查（除非自己跑命令摸索）。

出题后**人工复核一遍**，剔掉两类：

- ❌ 通识就能答对的（`netstat`→`ss`）
- ❌ 答案不唯一、要主观判断的

## 二、20 条配比与评分

| # | 类型 | 条数 | 判据 | 主要区分 |
|---|---|---|---|---|
| **A** | 环境特异事实 | 10 | 答案**含**目标串 且 **不含**错误串 | 小模型的成败 |
| **B** | 沙箱状态达成 | 6 | 一条 shell 检查命令的返回 | 小模型的成败 |
| **C** | 多步流程 | 4 | 工具调用次数 / 失败次数 / 耗时 | **大模型的效率** |

### A 类判法（最常用）

```python
{
  "task": "在这台机器上把 sshd 起来，告诉我用什么命令",
  "must_contain":     ["/etc/init.d/ssh"],
  "must_not_contain": ["systemctl start ssh"],
  "source_unit":      "case-0xx"          # 答案出处，必填
}
```

**`must_not_contain` 是关键**——它抓的正是"没有记忆时最容易给出的那个错答案"。

### B 类：只在 `~/workspace` 里做

```python
{
  "task": "把 workspace/logs 下所有 .log 归档到 workspace/archive/，保留原名",
  "check_cmd": "ls ~/workspace/archive/*.log | wc -l",
  "expect":    ">= 3"
}
```

🔴 **绝不设计"真把 sshd 弄坏再恢复"这类任务。** 14 天到截止，机器出事赔不起。
踩坑知识全部用 A 类测。

### C 类：四个指标一起记

```
工具调用次数 · 失败返回次数 · 墙钟耗时 · 是否最终成功
```

大模型无记忆时**多半也能做对，只是绕**——差异全在这四个数上。

## 三、三条公平性纪律（不守就 trivial）

**① 无记忆组必须同样允许跑命令调查。**
否则测的是"背没背过"，结论毫无意义。两组都能查，区别只是一组多注入了检索结果。

**② 两组提示词一字不差。** 唯一差别是上下文里多不多那段记忆。

**③ 每题独立会话。** 不许让前一题的上下文帮到后一题。
